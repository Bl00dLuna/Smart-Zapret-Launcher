🔥 ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ SMART ZAPRET LAUNCHER


1. 📦 Запуск всех конфигов
Что делает: Запускает конфиги из всех категорий

Категории (запускаются всегда):
- discord - для Discord
- youtube_twitch - для YouTube и Twitch
- gaming - для игр
- universal - для различных сайтов (самый низкий приоритет)

Как использовать:
- Для каждой категории выбираешь конкретный конфиг
- Можно выбрать случайный конфиг (R)
- Можно вернуться в меню в любой момент (B)

💾 Сохранения: Программа запоминает твой последний выбор и в следующий раз предложит запустить те же конфиги!


2. 🔧 Запуск отдельных конфигов
Что делает: Позволяет выбрать конкретные категории конфигов

Особенности:
- Можно выбрать несколько категорий через пробел (например: 1 3 4)
- В каждой категории можно пропустить выбор (S) или взять случайный (R)

💾 Сохранения: Есть кнопка (T) для запуска прошлых конфигов


⚙️ НАСТРОЙКИ В ГЛАВНОМ МЕНЮ

🔹 i - Использовать ipset global (Только для universal конфигов)
- ВКЛ - используется список IP для обхода блокировки
- ВЫКЛ - ipset отключен (пустой файл)
- Примечание: ipset global выключен по умолчанию

🔹 g - Использовать ipset gaming (Только для gaming конфигов)
- ВКЛ - используется список IP для обхода блокировки
- ВЫКЛ - ipset отключен (пустой файл)
- Примечание: ipset gaming выключен по умолчанию

🔹 u - Проверять обновления при запуске
- ВКЛ - обновления проверяются при запуске
- ВЫКЛ - обновления не будут проверяться при запуске
- Примечание: включено по умолчанию

🔹 h - Скрывать командную строку после запуска конфигов
- ВКЛ - cmd закрывается после запуска конфигов, работает в фоне
- ВЫКЛ - cmd остаётся открытым после запуска конфигов
- Примечание: выключено по умолчанию

🔹 l - Включить логи  
- ВКЛ - видно все окна WinWS, удобно для отладки
- ВЫКЛ - окна скрыты, работает в фоне
- Примечание: выключено по умолчанию

🔹 a - Настройки автозапуска
- Позволяет настроить конфиги, которые будут запускаться при старте windows

🔹 n - Сброс сетевых настроек
Делает следующее:

- Отключение Proxy в реестре — принудительно снимает галочку "Использовать прокси" в настройках Windows и стирает старый адрес сервера, который мог остаться от VPN.
- Сброс WinHTTP — очищает настройки прокси для системных служб. Бывает, что в браузере интернет есть, а программы не видят сеть — это лечит именно такую проблему.
- Удаление переменных среды — удаляет настройки (HTTP_PROXY), которые некоторые VPN прописывают глубоко в систему (переменные). Именно из-за них программы пытаются подключиться к удаленному VPN, даже если вы его давно снесли.
- Сброс Winsock — чинит внутренние ошибки Windows при работе с сетью.
- Очистка DNS кэша — заставляет компьютер заново узнавать IP-адреса сайтов, удаляя старые записи из памяти.

🚨 ВАЖНО: Все настройки сохраняются автоматически и будут применены при следующем запуске программы.
